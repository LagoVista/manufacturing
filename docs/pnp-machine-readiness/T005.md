# T005 — Auto feeder control panel

**Status:** Planned — awaiting coordination/implementation handoff.

**Workstream:** [Pick-and-place machine readiness](README.md)

## Goal

Expose practical operator controls and feedback for automatic feeders in the machine UI.

## Scope

Inspect existing automatic feeder contracts, transport and WPF controls. Reuse available commands for identification, status, feed/advance and other supported functions; display confirmed results, errors and connection state. Keep manual actions operator-triggered and prevent conflicting commands.

## Completion criteria

Operator can select the intended feeder, inspect state and safely exercise supported controls on hardware; failed commands remain visible and do not imply successful advancement.

## Dependencies

T004 if gantry decisions affect access or clearance.

## Review / handoff

Record source commit or PR, focused test results, physical verification (if applicable), remaining blockers and next step. Engineering completion is not proof of on-machine acceptance. Keep changes limited to this task and follow the coordination plan.
