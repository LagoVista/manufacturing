# T008 — Part inspection calibration (bottom camera)

**Status:** Planned — awaiting coordination/implementation handoff.

**Workstream:** [Pick-and-place machine readiness](README.md)

## Goal

Calibrate the upward-looking inspection camera for picked-part position and rotation.

## Scope

Review existing bottom-camera, nozzle and vision calibration paths. Verify scale, optical center, orientation/sign conventions and nozzle reference as applicable. Inspect a known picked component at controlled positions and angles; distinguish part offset from nozzle runout.

## Completion criteria

Repeatable measured part center and rotation for known test cases; correction direction verified on hardware before use in placement; document residuals and supported part/profile limits.

## Dependencies

T001; T007 for feeder-supplied test parts (known manual test parts may be used earlier).

## Review / handoff

Record source commit or PR, focused test results, physical verification (if applicable), remaining blockers and next step. Engineering completion is not proof of on-machine acceptance. Keep changes limited to this task and follow the coordination plan.
