## Authorized refinement — shared bottom camera and Full Diagnostics

Keep this in T001 and the existing camera-to-tool calibration screen. The purpose is trust in persisted geometry, not finer pickup tolerances. Pickup must be reliable; part inspection will later correct the actual picked component center and rotation.

- Add a checkbox labeled **Full Diagnostics**, default ON during development. Design so the default can later be changed to OFF without removing diagnostic capability.
- Both modes retain existing supervised two-pass pickup, explicit save/read-back, third pickup using the saved offset without a candidate pickup jog, and independent uncorrected bottom-camera validation. Turning diagnostics off must not waive acceptance checks.
- Complete and verify both head pickup offsets first. Use Head 1 as the reference to establish the single physical bottom-camera AbsolutePosition. Reuse CameraToolBottomCameraFraming and CenterNozzleInBottomCameraAsync (existing empirical 0.8 mm XY probes, bounded correction, safe travel, fresh optical evidence); propose the corrected shared camera XY in machine coordinates. Require explicit operator approval, authoritative save/read-back, and re-approach using the persisted camera location and persisted head offset.
- With Head 2 selected, approach the same saved bottom-camera location using its saved pickup offset. It must meet the existing 0.200 mm radial nozzle-to-camera-center tolerance **before any optical correction**. Verify Head 1 the same way. A disagreement is a geometry/coordinate-system diagnostic failure, not a reason to average head corrections, create head-specific inspection offsets, or silently jog into a passing result. Do not adjust the pickup offsets merely to center the bottom camera.
- Distinguish initial uncorrected approach, deliberate probe movement, computed optical correction, final centered reference, and pickup residual in evidence/UI. A successful framed pickup does not prove the saved inspection position. Keep pickup and framing corrections separate. The top/bottom camera mutual alignment is secondary to accurate selected-head inspection positioning.
- Full Diagnostics adds detailed persisted evidence and an operator-started extended repeatability run (proposed default 10 iterations, configurable; both heads). Record per-head initial XY/radial camera error, any probe/correction, pickup residual, vacuum pickup/release and camera failures, min/max/mean residuals, pass/fail and abort reason. Use existing calibration/history infrastructure. No automatic writes or hidden correction in diagnostic validation. Respect cancellation, existing safe Z/travel and recovery paths; stop on unsafe/invalid observations. Do not automatically start extended motion on opening the screen.
- Keep changes focused: no new calibration framework, no change to existing 0.200 mm tolerance, Known Location, camera scale, runout, fiducials, staging or vacuum settings. Preserve approved pickup offsets and existing stored camera location until explicitly approved replacement.
