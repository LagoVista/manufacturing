# T009 — Part on board calibration

**Status:** Planned — awaiting coordination/implementation handoff.

**Workstream:** [Pick-and-place machine readiness](README.md)

## Goal

Validate the full placement coordinate chain with a known PCB and component.

## Scope

Combine board transform, calibrated tool offset, feeder pickup position and bottom-camera inspection results. Use controlled dry runs and operator-supervised test placements; verify target XY, rotation and safe Z/clearance using existing motion controls. Measure actual placement using the position camera or other agreed method.

## Completion criteria

Demonstrate repeatable placement of a known part at intended board coordinates; report measured XY/rotation error and any remaining tolerances with operator acceptance.

## Dependencies

T001, T002, T006, T007, T008; resolve relevant T004 constraints.

## Review / handoff

Record source commit or PR, focused test results, physical verification (if applicable), remaining blockers and next step. Engineering completion is not proof of on-machine acceptance. Keep changes limited to this task and follow the coordination plan.
