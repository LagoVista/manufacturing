# T010 — AI job preparation

**Status:** Planned — awaiting coordination/implementation handoff.

**Workstream:** [Pick-and-place machine readiness](README.md)

## Goal

Define and demonstrate AI-assisted preparation of a pick-and-place job without autonomous machine execution.

## Scope

Review existing manufacturing job, BOM, placement, component and feeder models. Map approved input data into a reviewable proposed job; identify missing part/feeder/profile assignments and ambiguities rather than inventing them. Reuse existing job contracts and require operator review before any execution. Discuss scope before implementing major new infrastructure.

## Completion criteria

A representative job can be prepared and reviewed with explicit unresolved items; no silent substitutions or AI-triggered machine motion. Operator approves the job separately from execution.

## Dependencies

T002, T003, T005–T009 for end-to-end acceptance; planning can start earlier.

## Review / handoff

Record source commit or PR, focused test results, physical verification (if applicable), remaining blockers and next step. Engineering completion is not proof of on-machine acceptance. Keep changes limited to this task and follow the coordination plan.
