# T002 — Board fiducial calibration

**Status:** Authorized — proceed with engineering and supervised top-camera verification while T001 remains open.

**Workstream:** [Pick-and-place machine readiness](README.md)

## Goal

Establish a reliable board-local to machine-coordinate transform from actual PCB fiducials.

## Scope

Review BoardAlignmentManager and current board/fiducial models; use the correct camera profile and physical pixel scale, not hard-coded conversions. Detect/center board fiducials, calculate translation/rotation using the existing board coordinate convention, verify a separate known board point where available, and save against the correct board/setup.

## November 27 authorization and implementation priorities

Operator wants to proceed today without waiting for perfect T001 repeatability. T001 remains open; do not change its tolerances or claim acceptance. Board registration is a top-camera coordinate operation, independent of final nozzle/inspection acceptance. Require a current valid machine fiducial and calibrated top-camera scale before motion. Preserve T000.5 and T001.5 changes; use on-demand illumination where available and fresh settled observations.

- Start with the actual pick-and-place path: CircuitBoardViewModel.AlignBoardAsync, AlignFiducial, GetWorkSpaceLocation, CircuitBoardControl, PickAndPlaceJob/BoardFiducial and JobExecutionViewModel. Review legacy BoardAlignmentManager/BoardAlignmentPositionManager for relevant math only; do not revive an obsolete laser/GRBL workflow. Current legacy manager contains hard-coded 20 px/mm, a duplicated X test and controller-origin mutation; avoid carrying those forward.
- Audit the existing active Adjust/GetWorkSpaceLocation math (cross-axis scaling and division by expected X/Y separation). Use one rigid board-local to machine XY rotation/translation convention, including horizontal or vertical fiducial pairs; do not silently fit shear or scale to conceal calibration errors. Check actual consumer coordinates and angle units. Require at least two distinct sufficiently separated valid fiducials, reject ambiguous observations and report baseline length mismatch; if additional fiducials exist, use them as independent verification or document fit residuals. If only two exist, verify a separate known pad/board point where possible and distinguish that evidence from fit residual.
- Reuse existing board selection/setup and fiducial navigation UI, Board Fiducial vision profile, calibrated effective pixels/mm and established supervised locator/safety infrastructure. Keep the operator's existing coarse origin as initial approach; do not overwrite machine origin, machine fiducial, tool offsets or staging settings. Bound motions and acquisition; cancel/time out safely; no pickup or placement during this task.
- Stage candidate measurements and transform until validated; preserve prior good persisted values on failure, invalidate authorization for the failed/current setup rather than permitting stale alignment for job execution. Verify saved/read-back state where supported and scope alignment to the correct board revision/job/setup. Test all-or-nothing failure, missing/ambiguous targets, horizontal/vertical baselines, rotated boards, angle wrap and transform application.
- Keep this pragmatic: first get one real PCB aligned and independently verify a known point, then repeat alignment. Report signed XY and radial residuals in mm. Confirm acceptance threshold with operator; do not invent or tighten precision targets. No requirement to perfect T001 before beginning T002.

## Completion criteria

Known board aligns repeatably; verify independent target position and document residuals; failed observations do not overwrite good calibration.

## Dependencies

T001 remains an open dependency for reliable end-to-end pickup/inspection/placement, not a gate for T002 engineering or supervised top-camera board registration. Operator explicitly authorized proceeding November 27. A valid current machine-reference/position-camera baseline is still required. No production placement authorization from T002 alone.
