# T006 — Auto feeder placement calibration

**Status:** Planned — awaiting coordination/implementation handoff.

**Workstream:** [Pick-and-place machine readiness](README.md)

## Goal

Establish the physical installed location of an automatic feeder in machine coordinates.

## Scope

Reuse machine/staging plate reference geometry and existing calibration operation patterns where appropriate. Determine the actual feeder reference using the position camera or agreed physical reference; capture the verified offset with correct feeder identity and explicit persistence.

## Completion criteria

Re-select/reload the feeder and return to its reference repeatably; verify placement independently of pocket/part offsets; retain previous calibration on failed runs.

## Dependencies

T001, T005; T004 if relevant.

## Review / handoff

Record source commit or PR, focused test results, physical verification (if applicable), remaining blockers and next step. Engineering completion is not proof of on-machine acceptance. Keep changes limited to this task and follow the coordination plan.
