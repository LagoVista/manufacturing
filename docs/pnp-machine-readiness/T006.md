# T006 — Auto feeder placement calibration

**Status:** Implementation authorized; physical acceptance pending.

**Workstream:** [Pick-and-place machine readiness](README.md)

## Goal

Establish the physical installed location of an automatic feeder in machine coordinates.

## Scope

Reuse machine/staging plate reference geometry and existing calibration operation patterns where appropriate. Determine the actual feeder reference using the position camera or agreed physical reference; capture the verified offset with correct feeder identity and explicit persistence.

## Completion criteria

Re-select/reload the feeder and return to its reference repeatably; verify placement independently of pocket/part offsets; retain previous calibration on failed runs.

## Dependencies

T001, T005; T004 if relevant.

## Review / handoff

Record source commit or PR, focused test results, physical verification (if applicable), remaining blockers and next step. Engineering completion is not proof of on-machine acceptance. Keep changes limited to this task and follow the coordination plan.

## Implementation boundary — November 27

Reuse configured AutoFeeder, rail geometry, existing Feeder Fiducial circle profile, board fiducial freshness gate, bounded jog math and top-camera acquisition lease. Use the rail's configured SlotWidth, exclusive slot range and existing 0/180 degree rail convention; existing fiducial/pick offsets remain machine-relative. Select a saved feeder, unlock settings, confirm clearance, run Calibrate Feeder Placement, and explicitly Save the verified candidate. Check live Photon UUID before/after measurement and before saving; no feed, pick or inventory movement. Reload and Go To Fiducial for independent verification. Calibration failure or cancellation by context change does not overwrite the prior fiducial. Existing rail geometry assumptions need physical verification on both rail orientations. T007 owns pickup offset and presence.

Feeder-fiducial detection now requires one eligible physical circle (concentric edges may represent one target), consecutive frames, and position stability using the existing board geometry gate. The feeder uses its existing Hough profile; auto-threshold expansion to this profile is not included in T006.

## Operator UI refinement

Dedicated Auto Feeder Calibration modal follows the existing strip-feeder calibration window. Select one saved feeder from the machine list, confirm clearance, explicitly Run Calibration, inspect persistent progress/identity mismatch, then Save Placement. Save retains selection for Go To Fiducial. Closing discards an unsaved candidate and never cancels queued motion; cannot close during active operation. Future batch and current-job filters will supply a list of targets to the same single-feeder procedure, not introduce a second calibration algorithm. Larger white instructions/status. No automatic UUID reassignment on mismatch.

## Three-dot landmark — shared model first

The fixed Photon feeder PCB has three exposed copper circles, with a larger center circle. It is distinct from tape sprocket holes. The rail's calibrated FirstFeederOrigin (left-edge reference), slot pitch and slot index give the coarse location; the existing feeder FiducialOffset and PickOffset remain independent. Add the selectable shared profile `feederlandmark` (Feeder Landmark (3 Dots)), plus nullable physical center-dot diameter, side-dot diameter and center-to-side spacing in mm. No guessed measurements or new persisted defaults. The original `feederfiducial` and `custom` catalog entries are corrected without migrating or renaming saved profiles. Existing machine PUT /api/mfg/machine persists camera VisionProfiles; deploy the updated shared manufacturing model with the cloud host before storing new fields. This cut only establishes the shared model and catalog; the detector, marker measurements, full-screen workbench and physical validation are subsequent work. Existing single-circle procedure is not switched to this new key until the three-dot detector is implemented.

## Geometry workbench first cut

The existing Auto Feeders page now hosts a master/detail workbench; the shell hides the redundant left camera column only on this page and preserves right-side machine controls. Configured feeder list, live position camera, calculated rail/slot/landmark/pickup coordinates and saved offsets use existing models and math. Configuration and existing T005 diagnostics remain accessible in separate tabs. Navigation requires explicit clearance, saved feeder/live UUID, idle Manual machine, homed/origin-calibrated state, vacuum off, safe-height camera navigation and in-bounds targets. After movement the controller XY is read back and the existing bounded 30-second top light preview is requested. No offsets are written. The new profile is selected for landmark navigation only; no three-dot recognition or automatic centering is claimed. Batch preparation and T007 remain pending. Existing offset coordinate conventions intentionally unchanged; compare calculated positions physically before any migration.
