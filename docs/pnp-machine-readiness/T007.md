# T007 — Auto feeder part location and presence calibration

**Status:** Planned — awaiting coordination/implementation handoff.

**Workstream:** [Pick-and-place machine readiness](README.md)

## Goal

Calibrate the actual pickup point and determine whether a component is present after advancement.

## Scope

Use the verified feeder placement and current camera/profile scale. Measure the part pickup location and relevant pocket/advance geometry. Validate present/absent observations using known loaded and empty examples; distinguish operator confirmation from automated vision verification. Avoid unintended picks or inventory mutation during calibration.

## Completion criteria

Return to the correct pickup point across representative advances; demonstrate present/absent verification and a clear blocked state for missing/uncertain parts.

## Dependencies

T005, T006

## Review / handoff

Record source commit or PR, focused test results, physical verification (if applicable), remaining blockers and next step. Engineering completion is not proof of on-machine acceptance. Keep changes limited to this task and follow the coordination plan.
